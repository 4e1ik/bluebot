# Quickstart: Дата выкладки товара для админа

## Prerequisites

- Python 3.11+
- Зависимости из `requirements.txt`
- Для живого polling: `BOT_TOKEN`, `SUPERUSER_ID`, `SUPERUSER_USERNAME` в `.env`

## Checks

```bash
python -m unittest tests.test_categories tests.test_listing_date
```

Ожидание: все проверки зелёные. Они покрывают минский день на границе суток, строку карточки только для админа, дату в начале кнопки трёх каталожных списков, сокращение хвоста подписи и отсутствие даты у пользователя из белого списка.

Проверка запуска без ошибки импорта:

```bash
python -c "import bot.main"
```

Живой бот, если `.env` заполнен:

```bash
python main.py
```

Ожидание: в журнале есть `Bot started`, процесс не падает на старте.

## Manual path

1. Админом открыть категорию, подкатегорию и «Без категории». На кнопке товара дата стоит перед названием и ценой.
2. Открыть карточку того же товара. Строка даты совпадает с кнопкой и не содержит времени.
3. Сменить название, цену, фото и привязку. Дата остаётся прежней, пометка 🆕 не сбрасывается.
4. Тем же товаром зайти пользователем из белого списка. На кнопке и на карточке даты нет.
5. Открыть корзину, «Мои брони» и ожидающие подтверждения. Даты выкладки там нет.

Правила дня и текстов записаны в `contracts/listing-date.md` и `data-model.md`. Повторять их здесь не нужно.
