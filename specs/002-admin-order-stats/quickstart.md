# Quickstart: Статистика заказов и товаров

## Prerequisites

- Python 3.11+
- Зависимости из `requirements.txt`, включая Pillow
- Для живого polling: `BOT_TOKEN`, `SUPERUSER_ID`, `SUPERUSER_USERNAME` в `.env`

## Checks

```bash
python -m unittest tests.test_categories tests.test_stats
```

Ожидание: все проверки зелёные. Они покрывают оформление двух заказов, рост суммы без сдвига даты, разные окна товаров и заказов, разрезы, нули, среднюю, отказ удалить непустую запись и сохранность сумм после удаления товара.

Проверка запуска без polling-ошибки импорта:

```bash
python -c "import bot.main"
```

Живой бот, если `.env` заполнен:

```bash
python main.py
```

Ожидание: в журнале есть `Bot started`, процесс не падает на старте.

## Manual path

1. Админом создать категорию и подкатегорию, переименовать обе, перепривязать подкатегорию.
2. Создать товар, сменить имя, цену и привязку, удалить товар.
3. Удалить пустую подкатегорию и пустую категорию. Повторить удаление на записи с товаром и получить отказ.
4. Открыть «Статистика заказов» и «Статистика товаров».
5. На проверочной базе с 5 категориями, 50 товарами за год и подтверждёнными заказами за год хотя бы два окна и две категории отличаются в обоих отчётах.

Команды и ожидаемые цифры прогона записаны в `tests/test_stats.py` и в сценарии быстрой проверки `scripts/verify_stats_paths.py`, когда он добавлен реализацией. Повторять тела этих файлов здесь не нужно.
