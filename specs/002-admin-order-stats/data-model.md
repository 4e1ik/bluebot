# Data Model: Статистика заказов и товаров

## Order

Одно оформление корзины.

- `Order.id`: обязательный идентификатор
- `Order.user_id`: обязательный, кто оформил
- `Order.username`: может быть пустым
- `Order.submitted_at`: обязательный момент оформления, UTC
- `Order.confirmed_at`: пусто, пока ни один товар не подтверждён. После первого подтверждения не меняется

В отчёт заказов входят только записи с непустым `confirmed_at`. Сумма заказа — сумма его подтверждённых строк и может вырасти позже.

## OrderLine

Подтверждённый товар внутри заказа. Не удаляется вместе с товаром или бронью.

- `OrderLine.order_id`: обязательная связь с `Order`
- `OrderLine.item_id`: идентификатор товара на момент подтверждения, может указывать на уже удалённый товар
- `OrderLine.confirmed_at`: обязательный момент подтверждения этой позиции, UTC. Не равен дате заказа, если позицию подтвердили позже
- `OrderLine.price`: обязательная цена в этот момент, больше нуля
- `OrderLine.category_id` и `OrderLine.category_name`: заполнены, если товар был привязан прямо к категории. Иначе пусто
- `OrderLine.subcategory_id` и `OrderLine.subcategory_name`: заполнены вместе с `OrderLine.parent_category_id` и `OrderLine.parent_category_name`, если товар был в подкатегории
- Прямая категория и подкатегория одновременно не заполняются. Если не заполнено ни то ни другое, строка относится к «Без категории»

## Booking.order_id

Существующая бронь получает необязательную связь с `Order`. Новое оформление проставляет её всем позициям корзины. Старая бронь без связи при подтверждении получает свой новый заказ, чтобы не склеивать её с чужим оформлением.

## Category и Subcategory

Правила прежние, плюс удаление.

- Категория пустая, только если нет подкатегорий и нет товаров с прямой привязкой к ней, включая скрытые.
- Подкатегория пустая, только если нет товаров с этой подкатегорией, включая скрытые.
- Иначе удаление не выполняется.
- Удаление не трогает `OrderLine`.

## Окна

Граница нижняя включительно, верхняя — текущий момент.

- Сегодня: с 00:00 Europe/Minsk
- Неделя: с понедельника 00:00 текущей недели
- 2 недели: с понедельника 00:00 прошлой недели
- Месяц: с 1-го числа текущего месяца
- Квартал: с 1 января, 1 апреля, 1 июля или 1 октября
- Год: с 1 января
- Всё время: без нижней границы

Заказ попадает в окно по `Order.confirmed_at`. Товар попадает в окно по `OrderLine.confirmed_at`.

## Агрегаты

- Сводка заказов: число заказов окна и сумма их строк.
- Сводка товаров: число строк окна и сумма их цен.
- Категория получает прямые строки и строки своих тогдашних подкатегорий.
- Подкатегория получает только свои строки.
- «Без категории» получает строки без привязки.
- Сумма категорий окна равна сводке. Число заказов по категориям — это число разных заказов, у которых есть строка в категории; один заказ может войти в несколько категорий.
- Нулевые живые категории и подкатегории видны. Удалённая запись видна, только если по ней осталась сумма, и подписывается именем из снимка.
- При равном числе или сумме порядок имён как в каталоге: без учёта регистра, затем идентификатор. «Без категории» после именных записей при равенстве.
- Средняя за текущий календарный месяц: сумма окна, делённая на число. Один знак после запятой. При нуле средней нет.
- Суммы окон показываются целым числом Br, как `:.0f` в каталоге.
